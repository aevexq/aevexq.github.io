## ✨ Overview

AeveXQ is my personal portfolio, created to showcase my journey as a developer, share future projects, and explore new technologies.

Built with a minimalist dark aesthetic, electric cyan accents, and a focus on simplicity and usability.

## 🚀 Features

- **Responsive Design** — Adapts to different screen sizes.
- **Minimalist Interface** — Dark theme with electric cyan accents.
- **Smooth Navigation** — Sticky header and smooth scrolling between sections.
- **Dynamic Page Title** — Changes the browser tab title when visitors leave or return.
- **Automatic Copyright Year** — Updates the footer year dynamically.
- **Accessibility** — Semantic HTML and visible keyboard focus indicators.
- **Reduced Motion Support** — Respects the user's motion preferences.

## 💻 Getting Started

This project uses vanilla HTML, CSS, and JavaScript, so no dependencies or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/AeveXQ/aevexq.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd aevexq.github.io
   ```

3. Open `index.html` in your browser or use a local development server.
